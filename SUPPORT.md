# Support

Start with [installation and troubleshooting](docs/INSTALL.md) and `devguard doctor` (source checkout: `./scripts/devguard-local doctor`).

For bugs, use [GitHub Issues](https://github.com/Abhijan-Patra/DevGuard/issues/new/choose). Include OS/architecture, Python/Ollama/Docker/Gitleaks versions, the exact public model tag, the fixed error/reason code and minimal **synthetic** reproduction steps. State whether this is the local application or the read-only public tour.

Do not attach tokens, `.devguard/`, `.env`, databases, model weights, raw runtime logs, clipboard text, personal source or private test results. Review any diagnostic metadata before sharing it. Screenshots are optional for a UI layout problem; backend bug reports should use synthetic source, structured errors and independent tests.

This public preview has no uptime/support SLA, automatic recovery guarantee or guarantee of model accuracy. Use the [security reporting route](SECURITY.md) for vulnerabilities; do not post exploit details or credentials publicly.
