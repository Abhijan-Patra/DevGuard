# Implementation checklist

All items start unchecked. A checked item requires actual code and evidence; publishing these docs does not complete the application.

## Shared start

- [ ] Mac owners freeze contract v1 and independent expected outcomes.
- [ ] Each member branches into owned paths and reads their task file.
- [ ] Mac 1 completes real Gemma tool/memory trial and records digest/settings.
- [ ] Windows UI displays a persistent fixture-mode banner until connected.

## P0 privacy and clipboard

- [ ] Bound immutable input, trusted surface/destination metadata and policy revision.
- [ ] Detector plus contextual Gemma decisions, validated spans and held failures.
- [ ] Actual gate delivery with inspected receiver bytes, not only preview.
- [ ] Opt-in macOS text clipboard counter checks and bounded reads.
- [ ] Deduplication, rapid-copy cancellation, version conflict and own-write suppression.
- [ ] Explicit cleaned-copy action and disable clears transient state.
- [ ] Raw clipboard/secret values absent from logs, events, model debug dumps and exports.
- [ ] Oversize/non-text/unsupported host clearly labelled.
- [ ] Installed Codex hook trial and per-path coverage, or explicitly incomplete adapter status.
- [ ] Benign, contextual confidentiality, prompt-injection and unavailable-model cases recorded.

## P1 backend repair

- [ ] Bug evidence from source/diffs/logs/named API probes/tests, with no visual dependency.
- [ ] Approved snapshot includes relevant saved edits and input hashes.
- [ ] Baseline trusted operation test fails reproducibly.
- [ ] Genuine model actions/patch in restricted workspace.
- [ ] Same immutable verifier passes; model cannot edit expected outcomes.
- [ ] Review/apply separation, locked base checks, stale rejection and idempotency.
- [ ] Time/attempt/tool limits, cancellation and foreground priority.
- [ ] Healthy and unresolved cases recorded honestly.

## Submission

- [ ] Dashboard live/fixture status and integration limitations match reality.
- [ ] Actual resource/latency/evaluation results with unrun cases left UNRUN.
- [ ] Setup/reset instructions match executable code.
- [ ] MIT and third-party notices maintained; no weights/secrets/private history in Git.
- [ ] Confirm event track and multi-category submission rules.
- [ ] Rehearse within allotted demo time; preserve final hour for freeze/submission.
